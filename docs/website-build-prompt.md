# Website Build Prompt (Summary)

Source: `.amazonq/instr.md`

## Goal
Build a 6-page professional marketing website for Pooja Facility Management Services Pvt Ltd.

## Pages
1. Home — hero, services overview, sectors, why us, CTA
2. Services — detailed service cards
3. About Us — company story, values, leadership
4. Industries We Serve — sector descriptions
5. Contact Us — form + office details
6. FAQ — accordion

## Key constraints
- Do not invent business information
- Do not build dashboard, login, or database in this phase
- Contact form must show real validation and honest submission states
- No API secrets in frontend code
- Design must look professionally developed, not like a student project

## Stack decision (recorded 2025)
Plain HTML/CSS/JS for this phase. React + backend when dashboard modules are needed.
Colour palette: keep existing (navy `#0d2647`, green `#5a9e2f`, teal `#2f8fb0`).
